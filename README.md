## 🚀 Menjalankan Aplikasi

Aplikasi MVC di `prak7/` menggunakan PHP dan MySQL. Siapkan database dan sesuaikan konfigurasi koneksi di `koneksi.php`, lalu buka terminal pada folder `prak7` dan jalankan:

```bash
php -S localhost:8080
```

Setelah server berjalan, buka aplikasi:

| Aplikasi | Alamat lokal |
|:---|:---|
| 🎓 Akademik MVC | [localhost:8080/akademik-mvc](http://localhost:8080/akademik-mvc/) |
| 🛍️ Penjualan MVC | [localhost:8080/penjualan-mvc](http://localhost:8080/penjualan-mvc/) |
